# Синхронизация Obsidian на двух компьютерах

> Как настроить Obsidian так, чтобы заметки автоматически обновлялись на двух (и более) компьютерах одновременно.

---

## Сравнение методов

| Метод | Цена | Платформы | Автосинк | Конфликты | Сложность |
|-------|------|-----------|----------|-----------|-----------|
| **Obsidian Sync** | $4/мес | Все | Да | Решает сам | Легко |
| **Git + плагин** | Бесплатно | Win/Mac/Linux | Да (плагин) | Через merge | Средне |
| **OneDrive / Dropbox** | Бесплатно* | Win/Mac | Да | Риск дублей | Легко |
| **iCloud** | Бесплатно* | Mac/iOS | Да | Риск дублей | Легко |
| **Google Drive** | Бесплатно* | Win/Mac/Linux | Да | Риск дублей | Легко |
| **Syncthing** | Бесплатно | Win/Mac/Linux/Android | Да | Версионирование | Средне |
| **Remotely Save (плагин)** | Бесплатно | Все | Да | Решает сам | Легко |

*Бесплатно в рамках бесплатного тарифа облака

---

## Метод 1: Git + Obsidian Git (рекомендую)

> Лучший бесплатный способ — полная история изменений, бэкапы, работает на Win/Mac/Linux.

### Шаг 1: Создайте репозиторий на GitHub

1. Зайдите на https://github.com/new
2. Назовите репо (например, `obsidian-vault`)
3. Выберите **Private** (заметки = личные данные!)
4. Нажмите **Create repository**

### Шаг 2: Настройте первый компьютер

```bash
# Перейдите в папку с хранилищем Obsidian
cd /путь/к/вашему/хранилищу

# Инициализируйте git
git init
git remote add origin https://github.com/ваш-логин/obsidian-vault.git

# Первый коммит
git add .
git commit -m "Initial vault"
git push -u origin main
```

### Шаг 3: Установите плагин Obsidian Git

1. Obsidian → Settings → Community plugins → Browse
2. Найдите **Obsidian Git**
3. Установите и включите

### Шаг 4: Настройте автосинхронизацию

В настройках плагина Obsidian Git:

| Параметр | Значение | Что делает |
|----------|----------|-----------|
| Auto pull interval | `5` | Тянет изменения каждые 5 минут |
| Auto commit interval | `5` | Коммитит изменения каждые 5 минут |
| Auto push interval | `5` | Пушит изменения каждые 5 минут |
| Pull on startup | `Вкл` | Тянет при запуске Obsidian |
| Push on backup | `Вкл` | Пушит после каждого бэкапа |

### Шаг 5: Настройте второй компьютер

```bash
# Клонируйте репо
git clone https://github.com/ваш-логин/obsidian-vault.git

# Откройте эту папку как хранилище в Obsidian
# File → Open Vault → выберите клонированную папку
```

Установите тот же плагин Obsidian Git с теми же настройками.

### Готово!

Теперь при каждом изменении заметки:
```
Комп 1: редактирование → auto commit → auto push → GitHub
GitHub → auto pull → Комп 2: обновление
```

## Метод 2: Obsidian Sync (платный, самый простой)

> Официальный сервис от разработчиков Obsidian. $4/мес (или $48/год).

### Настройка

1. Obsidian → Settings → Core plugins → Sync → Включить
2. Войдите в аккаунт Obsidian
3. Создайте удалённое хранилище
4. На втором компьютере: подключитесь к тому же удалённому хранилищу

### Плюсы
- End-to-end шифрование
- Синхронизация настроек, плагинов, тем
- Работает на всех платформах включая мобильные
- Автоматическое разрешение конфликтов
- История версий (до 12 месяцев)

### Минусы
- Платный ($4/мес)
- Максимум 10 хранилищ
- Лимит 10 ГБ на хранилище

## Метод 3: OneDrive / Dropbox / Google Drive

> Самый простой бесплатный способ, но есть риск конфликтов файлов.

### Настройка (OneDrive)

1. Переместите папку хранилища Obsidian внутрь папки OneDrive
2. На обоих компьютерах установите OneDrive и войдите в один аккаунт
3. Откройте хранилище из папки OneDrive на обоих компьютерах

### Настройка (Remotely Save плагин — лучше!)

1. Установите плагин **Remotely Save** (Community plugins → Browse)
2. В настройках плагина выберите облако: OneDrive, Dropbox или S3
3. Нажмите **Auth** → авторизуйтесь
4. Первая синхронизация: нажмите иконку стрелки в боковой панели
5. На втором компе: создайте хранилище с тем же именем → установите плагин → авторизуйтесь → синхронизируйте

### Важно

- **Не редактируйте** одну и ту же заметку на двух компах одновременно
- Облачные сервисы могут создавать дубли файлов при конфликтах
- Google Drive **не работает на iOS** (ограничение Apple)
- Remotely Save решает большинство проблем с конфликтами

## Метод 4: Syncthing (P2P, без облака)

> Прямая синхронизация между компьютерами без облака. Полная приватность.

### Настройка

1. Установите Syncthing на оба компа: https://syncthing.net
2. Откройте веб-интерфейс (`http://localhost:8384`)
3. Добавьте устройства друг к другу (по Device ID)
4. Создайте общую папку → укажите путь к хранилищу Obsidian
5. Папка будет синхронизироваться в реальном времени

### Плюсы
- Полностью бесплатный и open-source
- Данные не проходят через облако
- Работает в локальной сети и через интернет
- Версионирование файлов

### Минусы
- Оба компьютера должны быть включены для синхронизации
- Нет мобильной версии для iOS
- Начальная настройка сложнее

## Лучшие практики

### Избегайте конфликтов

1. **Не редактируйте одну заметку** на двух компах одновременно
2. **Закрывайте Obsidian** или дождитесь синхронизации перед работой на другом компе
3. **Включите auto pull при запуске** — всегда начинайте с актуальной версии

### Бэкапы

1. Используйте Git даже если синхронизируете через облако — это бэкап
2. Периодически делайте ZIP-архив хранилища
3. Плагин **Obsidian Git** = синхронизация + бэкап в одном

### Что синхронизировать

| Синхронизировать | Не синхронизировать |
|-----------------|-------------------|
| Все `.md` файлы | `.obsidian/workspace.json` |
| Вложения (картинки) | `.obsidian/workspace-mobile.json` |
| `.obsidian/plugins/` (по желанию) | Кэш плагинов |
| `.obsidian/themes/` (по желанию) | `.trash/` |

### Пример `.gitignore` для Git-синхронизации

```
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.obsidian/.obsidian/cache
.trash/
```

## Какой метод выбрать?

```
Хочу бесплатно + историю изменений?
  → Git + Obsidian Git плагин

Хочу максимально просто и не парюсь о $4/мес?
  → Obsidian Sync

Уже пользуюсь OneDrive/Dropbox?
  → Remotely Save плагин

Хочу полную приватность без облака?
  → Syncthing

Только Mac + iPhone?
  → iCloud
```
