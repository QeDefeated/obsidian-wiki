# Deep Research Prompt — Гражданство в Латинской Америке

> Промпт для ChatGPT Deep Research / Perplexity Pro / Gemini Deep Research

---

## Промпт

```
Проведи глубокое исследование на тему: получение гражданства (паспорта) в странах Латинской Америки БЕЗ использования:
- программ «гражданство за инвестиции» (Citizenship by Investment)
- визы рантье / рентиста (Rentista / Pensionado / Passive Income Visa)
- программ «золотая виза»

Рассмотри КАЖДУЮ страну Латинской Америки отдельно (от Мексики до Аргентины, включая Карибский бассейн — Доминикана, Куба и т.д.).

Для каждой страны дай:

### 1. Доступные пути к гражданству (без инвестора/рантье)
- Натурализация через проживание (residencia temporal → permanente → ciudadanía):
  - Минимальный срок проживания до подачи на гражданство
  - Требование непрерывного пребывания в стране (сколько дней/год нужно быть физически)
  - Основания для получения временного ВНЖ (trabajo, estudios, reunificación familiar, refugio, convenio Mercosur и т.д.)
- Гражданство по браку:
  - Срок проживания после заключения брака
  - Нужно ли проживать в стране или достаточно быть за рубежом
- Гражданство по происхождению (jus sanguinis):
  - Какие поколения могут претендовать
  - Есть ли программы для потомков (итальянцев, испанцев, немцев и т.д.)
- Гражданство по рождению (jus soli):
  - Получает ли ребёнок, рождённый на территории, автоматическое гражданство
  - Даёт ли это родителям право на упрощённую натурализацию
- Особые программы:
  - Гражданство для беженцев / лиц без гражданства
  - Специальные соглашения (Меркосур, CARICOM, Андское сообщество)
  - Ускоренная натурализация для определённых национальностей
  - Гражданство для деятелей культуры / спортсменов / учёных

### 2. Практические детали процесса
- Стоимость процедуры (госпошлины, адвокат)
- Язык: нужно ли сдавать экзамен / собеседование
- Допускается ли двойное гражданство (с Россией, Украиной, Беларусью, странами ЕС)
- Сроки рассмотрения заявлений (реальные, не официальные)
- Можно ли подавать документы находясь за пределами страны

### 3. Рейтинг и сравнение
Составь итоговую таблицу со следующими колонками:
| Страна | Самый быстрый путь | Срок до гражданства | Требование проживания (дни/год) | Двойное гражданство | Jus soli | Сложность (1-10) | Комментарий |

Отсортируй по скорости получения гражданства (от самого быстрого к самому долгому).

### 4. ТОП-5 стран рекомендация
Выдели ТОП-5 стран для гражданина РФ / СНГ, который:
- Не хочет инвестировать крупные суммы
- Готов жить 2-5 лет в стране
- Работает удалённо (фриланс / онлайн-бизнес)
- Хочет получить паспорт с хорошей безвизовой зоной
- Ценит безопасность, климат и стоимость жизни

Для каждой страны из ТОП-5 дай:
- Пошаговый план действий (от въезда до получения паспорта)
- Ориентировочный бюджет на весь процесс
- Силу паспорта (Henley Index, количество безвизовых стран)
- Реальные подводные камни и риски
- Лучший город для проживания (стоимость, безопасность, комьюнити экспатов)

### 5. Источники
Приведи ссылки на:
- Официальные миграционные законы каждой страны
- Сайты миграционных ведомств
- Актуальные форумы / группы экспатов
- Примеры реальных кейсов (если есть)

ВАЖНО:
- НЕ включай программы, требующие доказательства дохода / депозита / инвестиций как условие визы
- Фокус на путях, доступных человеку со средним доходом, работающему удалённо
- Все данные должны быть актуальны на 2025-2026 год
- Указывай, если закон менялся недавно или есть законопроект об изменениях
- Пиши на русском языке
```
