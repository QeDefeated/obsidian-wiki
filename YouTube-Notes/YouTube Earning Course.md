# Бесплатный курс: заработок в интернете через YouTube

> Бесплатный курс от Матвея Северянина — 7 блоков: мотивация, продажи, контент, нейросети. Главная идея: YouTube = социальный лифт, который позволяет зарабатывать из любой точки мира.

## Блок 1: Мотивация — почему YouTube

### YouTube как социальный лифт

- Матвей начал с микрофона за 90 руб., первое видео по Warcraft — за ночь набрал 111 подписчиков
- За **855 дней** заработал на квартиру (1.6 млн руб.), ни разу не показав лицо
- YouTube даёт: клиентов, связи, социальный капитал, возможность работать из любой страны

### Примеры из реальной жизни

| Кто | Что делает | Результат |
|-----|-----------|-----------|
| Дима (Dota 2) | Переехал в Бразилию, продаёт недвижимость | Новый бизнес в другой стране через YouTube |
| Вадим из Уругвая | Маленький канал про переезд | Консультации по ПМЖ и гражданству |
| Самогон Саны Саныч | Варит самогон в деревне | 259K подписчиков, ~$500/мес монетизация + спонсоры |
| Девочка из Афганистана | Рисует и учит русский в Казахстане | Растущий канал, скоро монетизация |
| Илья Доминикана | Влог про жизнь в Доминикане | Бизнес на турах для русских |

### 3 пути заработка на YouTube

1. **Продажа своих услуг/товаров** — консультации, курсы, недвижимость
2. **Реклама** — интеграции, спонсоры
3. **Монетизация YouTube** — прямой доход от просмотров

> Все три работают и по отдельности, и в синергии.

## Блок 2: Продажи в переписке (Андрей)

### 5 этапов продажи

```
1. Установление контакта
2. Выявление потребностей  ← САМЫЙ ВАЖНЫЙ
3. Презентация продукта
4. Работа с возражениями
5. Закрытие сделки
```

### Установление контакта

- **Формула:** Приветствие + Представление + Комплимент/Благодарность + Вопрос
- Не давить, не впаривать с первого сообщения
- Клиент должен чувствовать индивидуальный подход, а не шаблон Ctrl+C / Ctrl+V

### Выявление потребностей — ключевой этап

- Задавайте вопросы: "Какие цели?", "Что для вас важно?", "Какой бюджет?"
- **Кто задаёт вопросы — тот ведёт диалог**
- Без выявления потребностей презентация будет "вслепую" — как стрелять с закрытыми глазами
- Иногда нужно отказать клиенту, если продукт ему не подходит

### Презентация продукта

- Адаптируйте под конкретного клиента (не общая для всех)
- Голосовые сообщения = ускорение (но сначала спросите разрешение!)
- Если клиент задаёт много вопросов — чередуйте: ответ + ваш вопрос

### Работа с возражениями — "Дорого"

| Стратегия | Как работает |
|-----------|-------------|
| Сравнение | "С чем сравниваете? Посмотрите, есть варианты за 20K, 50K и 100K" |
| Дробление цены | "В день это стоимость одного кофе" |
| Уточнение бюджета | "Какой бюджет закладывали?" → предложить по кошельку |
| Стоимость бездействия | "Что будет через полгода, если ничего не изменить?" |

### Инструменты закрытия при "Дорого"

1. **Рассрочка** — но не предлагать сразу, сначала показать ценность
2. **Специальные условия** — "3 дня с поддержкой за 30K, потом довносите"
3. **Альтернативные продукты** — консультация вместо полного курса
4. **Другой период** — бронь 10%, запись на следующую неделю

### Фатальные ошибки менеджера

1. **Потеря клиента** — просто перестать отвечать (должностное преступление!)
2. **Автоответы** — не решают вопрос, раздражают, удлиняют переписку
3. **Думать за клиента** — "наверное, ему дорого" без проверки
4. **Презентация без выявления потребностей** — стрельба вслепую
5. **Не запрашивать разрешение** на голосовые/звонки

> Написать 1-3 раза после молчания — допустимо. Клиент мог просто забыть.

## Блок 3: Контент и копирайтинг

### Правила работы с текстом

#### 1. Одна мысль = одно предложение
- Не перегружать предложения
- Разбивать длинные конструкции на короткие

#### 2. Сокращайте глаголы
- "Помогает поддерживать" → **"Поддерживает"**
- "Начинаешь наносить" → **"Наносишь"**
- "Могут подчеркнуть" → **"Подчеркнёт"**
- Два глагола → превращайте в один

#### 3. Убирайте слова, не влияющие на смысл
- "Довольно распространённая проблема, с которой сталкиваются многие" → **"Проблема"**
- Наречия времени ("сегодня", "однако") — чаще всего лишние
- Качественные прилагательные ("серьёзный", "часто") — убирать

#### 4. Избегайте тавтологии
- Не повторяйте одно слово дважды подряд
- Используйте синонимы и местоимения
- **Упражнение:** напишите слово → подберите 5 синонимов → заучите

#### 5. Конкретика вместо оценок
- **Плохо:** "Удобный мессенджер" (у каждого своё понятие удобства)
- **Хорошо:** "Жёлтая кружка в виде Гомера Симпсона" (факт, не оценка)
- Не пишите "красивый", "дорогой" — давайте конкретные описания

#### 6. Не используйте скобки
- Всё, что в скобках, можно сказать и без них
- Перефразируйте в отдельное предложение

### Структура истории (сторителлинг)

```
1. Анонс (хук) — "Я ждал его 3 часа на морозе"
2. Ввод в контекст — кто, где, когда
3. Развитие сюжета — не затягивать!
4. Кульминация — ради чего рассказываете
5. Развязка — что произошло дальше + личный вывод
```

> Правило: читатель должен "видеть картинку" в голове. Если он не может представить — текст плохой.

## Блок 4: Визуализация контента

### Принцип: показывай, а не рассказывай

- Пример Apple MacBook: сайт не пишет "классный ноутбук" — **показывает** сценарии использования
- Картинка создаёт ощущение и мечту — текст этого не может
- Сначала соберите визуальный ряд, потом пишите текст

### Порядок создания контента

```
1. Идея → 2. Визуализация (фото, видео, графики)
→ 3. Текст → 4. Заголовок → 5. Публикация
```

## Блок 5: Заголовки — 7 "заклинаний"

| Заклинание | Принцип | Пример |
|------------|---------|--------|
| **Авторитетус** | Ссылка на известную личность | "Дамблдор раскрыл 3 секрета" |
| **Эмоциус Провоцитус** | Вызвать сильную эмоцию | "Нахер маглов, мы будем волшебниками" |
| **На самом деле** | Посеять сомнение в знаниях | "Как на самом деле стать волшебником" |
| **Актуальность Титус** | Привязка к моменту/событию | "Задолбала работа? Стань волшебником" (пн, 7:00) |
| **Простотус** | Обещание простого решения | "5 шагов", "Топ-7 заклинаний" |
| **Однокровкус** | Таргетинг на группу | "Слизеринцы узнали заклинания..." |
| **Цитатус** | Вырвать цитату из контекста | "Я ждал его 3 часа на морозе" |

> Мат = эмоция. Используйте как специю — не переборщите. Если подходит архетипу — нормально.

## Блок 6: Нейросети для контента

### Принципы работы с AI

- **Вы = главред**, нейронка = младший сотрудник
- Чем расплывчатее задание → тем хуже результат
- Пишите **максимально подробные промты** (экономия коинов)
- Лайфхак: попросите ChatGPT написать промт для другой нейросети

### Когда использовать нейронки

| Да | Нет |
|----|-----|
| Нет возможности сделать фото | Личный блог (нейротексты отталкивают) |
| SEO-статьи (качество не критично) | Когда можно сделать быстрее вручную |
| Поджимают сроки | Когда одной клавишей можно решить задачу |
| Прототипы и черновики | Финальный контент без редактуры |

### Инструменты

- **Транскрипция YouTube** → загрузить в ChatGPT/DeepSeek → пересказ, идеи для постов
- **Генерация изображений** — Midjourney, Шедеврум, Нанобана
- **ChatGPT** — промты, рерайт, структурирование
- **Грок** — альтернатива для текстов

### Пирамида проверки нейроконтента

```
1. Смысл — отвечает ли целям аудитории?
2. Визуал — насколько хороша картинка?
3. Текст — насколько хорошо написано?
```

> Бесщётковая ТЗ = результат КЗ (плохое задание = плохой результат)

## Блок 7: Приоритеты и тайм-менеджмент

### Главная мысль

> Если у вас чего-то нет — значит, это не приоритет. Другого ответа нет.

- Нет YouTube → YouTube не приоритет
- Нет английского → английский не приоритет
- Нет плана на неделю → планирование не приоритет

### Матрица Эйзенхауэра

```
         Срочно         Не срочно
Важно    [ ДЕЛАЙ ]      [ ПЛАНИРУЙ ]
Неважно  [ ДЕЛЕГИРУЙ ]  [ УДАЛИ ]
```

### Враги продуктивности

- **Обезьянка немедленного удовольствия** (Wait But Why) — отвлекает от целей
- **Прокрастинация** — занят, но не тем, что ведёт к цели
- **Перфекционизм** — "идеально" = "никогда"

### Практические советы

1. Напишите список дел → раскидайте по матрице Эйзенхауэра
2. Смотрите обучающий материал в одно и то же время дня
3. 80% людей не делают домашки — будьте в 20%
4. Не важно, какой планировщик — важно, что он есть
