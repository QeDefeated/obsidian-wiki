# 5 оригинальных сценариев ASMR Girlfriend видео

> **Жанр:** ASMR Companion / Girlfriend Experience
> **Основа:** Написаны на базе анализа паттернов жанра (см. [[ASMR Genre Analysis]] и [[ASMR Girlfriend Patterns]])

---

## Общая структура всех сценариев

```
Приветствие → Фиксация стресса → Релаксация (ASMR + дыхание) → Аффирмации → CTA + Прощание
```

Все сценарии используют:
- Дыхательную технику 4-6-8 (вдох-4, задержка-6, выдох-8)
- CTA через комментарии (позитивные вопросы)
- ASMR-триггеры с вербальным описанием
- Аффирмации: работа, доброта, важность, любовь
- Нормализация отдыха и уязвимости

---

## Видео 1: «Ты наконец дома»

| Параметр | Значение |
|----------|----------|
| **Концепция** | Поздний вечер, партнёрша ждала весь день. Усталость от работы, массаж рук |
| **ASMR-триггеры** | Расчёсывание волос, тэппинг по дереву, стеклянный стакан |
| **Длина** | ~12 минут |
| **Эмоция** | Забота, безопасность, отдых |

**Ключевые моменты:**
- Встреча уставшего партнёра — "Не говори ничего пока. Просто иди сюда"
- Дыхание 4-6-8 вместе
- CTA: "Напиши одну вещь, которая сегодня получилась"
- Аффирмация: "Я горжусь тобой. Не за результаты — за то, что ты есть"

## Видео 2: «Воскресный страх — вместе»

| Параметр | Значение |
|----------|----------|
| **Концепция** | Sunday scaries — тревога перед новой неделей |
| **ASMR-триггеры** | Звуковая чаша (528 Hz), спрей для лица, мягкий тэппинг |
| **Длина** | ~10 минут |
| **Эмоция** | Поддержка, преодоление тревоги |

**Ключевые моменты:**
- Фиксация тревоги: "Воскресенье умеет давить"
- Рационализация: "Всё, что тебя беспокоит — это прогнозы, а прогнозы почти всегда хуже реальности"
- CTA: "Напиши одну вещь, которую ждёшь на этой неделе"
- Техника: звуковая чаша + спрей для переключения внимания

## Видео 3: «Ты имеешь право плакать»

| Параметр | Значение |
|----------|----------|
| **Концепция** | Мужская уязвимость, разрешение на чувства, мягкая поддержка |
| **ASMR-триггеры** | Расчёсывание, бусины/чётки, дыхание |
| **Длина** | ~13 минут |
| **Эмоция** | Принятие, уязвимость, глубокая эмпатия |

**Ключевые моменты:**
- Снятие стигмы: "Слёзы — это не слабость. Это честность"
- Метафора: "Человек, который так привык нести, что забыл каково это — положить груз"
- CTA: "Напиши одно слово — как ты сейчас" + "Ответь кому-то в комментариях"
- Самое эмоционально глубокое видео из пяти

## Видео 4: «Послеобеденный сон — не уходи»

| Параметр | Значение |
|----------|----------|
| **Концепция** | Ленивый выходной, совместный сон, медитативное |
| **ASMR-триггеры** | Шёпот, звук ткани, очень медленное дыхание, тишина |
| **Длина** | ~15 минут (с длинными паузами) |
| **Эмоция** | Покой, разрешение на безделье |

**Ключевые моменты:**
- Паузы как основной инструмент (до 30 секунд тишины)
- Нормализация отдыха: "Ты заслужил этот момент не потому что завершил что-то важное, а просто потому что ты есть"
- CTA: "Что ты планируешь сегодня ДЛЯ СЕБЯ?"
- Самое медитативное видео — минимум слов, максимум пауз

## Видео 5: «Спа-вечер — только для тебя»

| Параметр | Значение |
|----------|----------|
| **Концепция** | Домашний спа-вечер, много ASMR-инструментов |
| **ASMR-триггеры** | Звуковая чаша, стрессовый шарик, расчёска, роллер, спрей |
| **Длина** | ~14 минут |
| **Эмоция** | Забота, удовольствие, самоценность |

**Ключевые моменты:**
- Структурированное — каждый инструмент как этап
- Звуковая чаша → стрессовый шарик → расчёсывание → спрей
- CTA: "Напиши одно качество, которым гордишься. Не достижение — именно качество"
- Финал: "Ты заслуживаешь таких вечеров. Регулярно. Не в награду"

## Производственные заметки

**Элементы из анализа жанра:**
- Дыхание 4-6-8 (из транскрипций — 10/12 видео)
- CTA через позитивные вопросы о себе
- Структура: приветствие → проблема → инструмент → аффирмации → прощание

**Отличия от типичного контента жанра:**
- Убраны прямые английские фразы — всё на русском
- Большая психологическая глубина в обоснование техник
- Видео 3 фокусируется на теме мужской уязвимости (в оригиналах периферийная)
- Видео 4 экспериментирует с паузами как основным инструментом
