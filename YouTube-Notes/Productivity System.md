## 5 правил продуктивности Katie

### Правило 1: Определи свои Non-Negotiables
**Non-negotiables** = действия, которые ты делаешь КАЖДУЮ неделю, несмотря ни на что.

Примеры Katie:
- 1 YouTube видео/неделю
- 3 Instagram поста/неделю
- 1 newsletter/неделю
- Ежедневная физическая активность

> **Принцип:** Лучше меньше, но регулярно. Выбери 3-5 вещей и ДЕЛАЙ их каждую неделю.

### Правило 2: Time Blocking (блоки времени)
- Выдели конкретные блоки времени для каждого типа задач
- НЕ мультитаскай - одна задача за один блок
- Используй календарь как план действий, а не просто расписание встреч

```
Пример блоков:
09:00-12:00 — Съемка / запись
12:00-13:00 — Обед (без работы!)
13:00-16:00 — Монтаж / редактирование
16:00-17:00 — Email / админ
```

### Правило 3: Batch Everything (батч всё)
- Группируй похожие задачи в один день
- Контекстное переключение = враг продуктивности
- См. [[Instagram Batch Creating]] и [[Weekly Productivity Routine]]

### Правило 4: Используй правильные инструменты
**Notion** - центральный хаб Katie для всего:
- Контент-календарь
- Список идей
- Трекер бренд-партнерств
- Персональные цели и привычки

**Другие инструменты:**
- Google Calendar для time blocking
- iPhone Notes для быстрых идей
- Notion AI для помощи с текстами

### Правило 5: Rest is Productive (отдых = продуктивность)
- **Отдых - это не лень, это инвестиция**
- Выгорание = нулевая продуктивность
- Выходные = выходные (без контента!)
- Хобби вне работы подпитывают креативность

> *"Non-hustle version"* = ты можешь быть успешным креатором, не работая 24/7

## Борьба с прокрастинацией

| Проблема | Решение |
|----------|---------|
| "Не хочу снимать" | Начни с самой легкой задачи |
| "Нет идей" | Загляни в Ideas Bank |
| "Слишком много дел" | Выбери 3 главных задачи на день |
| "Устал" | Отдохни. Серьезно. |
| "Не вижу результатов" | Посмотри аналитику за 3 месяца, не за 1 день |
