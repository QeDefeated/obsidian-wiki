# Долговая спираль США: проценты съедают бюджет

> США уже платят процентами — четверть налогов уходит на обслуживание долга, а без FICA-взносов эта доля достигает 36%

---

## Ключевые цифры (2026 прогноз)

| Показатель | Значение |
|---|---|
| Расходы на обслуживание госдолга | ~$1,3 трлн/год |
| Общие налоговые поступления | ~$5,5 трлн/год |
| Доля процентов от всех налогов | ~24% |
| Доля процентов без FICA | ~36% |

---

## Что такое FICA

FICA (Federal Insurance Contributions Act) — обязательные взносы с зарплат работников и работодателей, которые идут строго на:

- **Social Security** — пенсионное и социальное обеспечение
- **Medicare** — медицинское страхование для пожилых

Эти деньги технически "зарезервированы" и не могут тратиться на обслуживание долга. Поэтому если считать только "свободные" доходы бюджета, нагрузка процентов выглядит ещё тяжелее.

---

## Почему это долговая спираль

```
┌──────────────────────────────────────────────────┐
│                                                  │
│   Государство берёт в долг                       │
│           ↓                                      │
│   Растут проценты по долгу                       │
│           ↓                                      │
│   Нужно больше денег на проценты                 │
│           ↓                                      │
│   Берут ещё больше в долг                        │
│           ↓                                      │
│   Проценты растут ещё быстрее                    │
│           ↓                                      │
│   ∞ цикл пока пирамида не рушится               │
│                                                  │
└──────────────────────────────────────────────────┘
```

### Механика проблемы

1. **Ставки выросли** — ФРС поднимала ставки для борьбы с инфляцией, и теперь каждый новый выпуск облигаций обходится дороже
2. **Долг рефинансируется** — старые дешёвые облигации истекают, их заменяют новыми по высоким ставкам
3. **Дефицит бюджета** — расходы превышают доходы, разницу покрывают новым долгом
4. **Рост процентов обгоняет рост экономики** — когда r > g (ставка > рост ВВП), долговая нагрузка автоматически растёт

---

## Что это значит на практике

- **$1 из каждых $4** собранных налогов уходит кредиторам, а не на дороги, армию, образование
- **Без FICA**: $1 из каждых $3 — на проценты, ещё до финансирования чего-либо полезного
- Обслуживание долга уже обогнало расходы на оборону (~$900 млрд) и стало крупнейшей статьёй бюджета
- Каждое повышение ставки ФРС увеличивает стоимость обслуживания на десятки миллиардов

## Аналогия

> Как наркоман с дозой — государство не может перестать занимать, потому что уже не может обслуживать существующий долг без новых заимствований. Классическая структура финансовой пирамиды: старые обязательства покрываются новыми деньгами.

---

## Возможные сценарии

| Сценарий | Вероятность | Последствия |
|---|---|---|
| Инфляционное обесценивание долга | Высокая | Доллар слабеет, импорт дорожает, уровень жизни падает |
| Реструктуризация/дефолт | Низкая | Глобальный финансовый кризис, крах доверия к доллару |
| Жёсткая экономия (austerity) | Средняя | Сокращение соцпрограмм, рецессия |
| Рост экономики обгоняет долг | Низкая | Единственный "мягкий" выход, требует технологического рывка |
