## Главный инсайт

Планирование контента помогло Katie **пробить плато роста** и достичь **200K подписчиков** в Instagram, сохраняя work-life balance. Секрет: стратегическое соответствие идей → форматов → целей.

---

## 4-шаговый процесс планирования

### Шаг 1: Определи контент-столпы (Content Pillars)

Контент-столпы = 3-5 основных тем, о которых ты постишь. Все посты должны вписываться в один из столпов.

**Пример Katie:**
- Стратегия YouTube
- Instagram советы
- Оборудование и инструменты
- Лайфстайл контент-креатора
- Мотивация / за кулисами

> **Правило:** Если пост не вписывается ни в один столп - не публикуй

### Шаг 2: Генерация идей

**Источники идей:**
- Комментарии и DM подписчиков
- Вопросы из Stories Q&A
- Трендовые аудио / форматы
- Собственный опыт и уроки
- Конкуренты (вдохновение, не копирование)
- Новости и обновления платформ

**Контент-банк в Notion:**
- Записывай ВСЕ идеи сразу (не фильтруй на этом этапе)
- Раз в неделю выбирай 5-7 лучших
- Удаляй устаревшие идеи

### Шаг 3: Сопоставь идею с форматом

| Цель | Лучший формат | Почему |
|------|---------------|--------|
| **Охват** (новые подписчики) | Reels | Алгоритм продвигает видео |
| **Вовлеченность** | Карусели | Люди сохраняют полезное |
| **Доверие** | Stories | Личное и аутентичное |
| **Экспертиза** | Посты с текстом | Глубокий контент |
| **Продажи** | Stories + посты | Прямые CTA |

### Шаг 4: Составь контент-календарь

**Рекомендуемая частота:** минимум 3 раза/неделю

**Шаблон недели:**
```
Пн: Reel (охват) - тренд + столп 1
Ср: Карусель (вовлеченность) - советы по столпу 2
Пт: Reel (охват) - за кулисами + столп 3
+ Stories каждый день
```

---

## Стратегия контента по воронке

```
ВЕРХ ВОРОНКИ (охват):
  → Трендовые Reels
  → Развлекательный контент
  → Относимый (relatable) контент

СЕРЕДИНА (вовлеченность):
  → Образовательные карусели
  → Советы и лайфхаки
  → За кулисами

НИЗ (конверсия):
  → Отзывы / кейсы
  → Прямые продажи
  → Ссылка в био
```

## Инструменты для планирования

| Инструмент | Для чего |
|-----------|----------|
| **Notion** | Контент-банк и календарь |
| **HubSpot** (бесплатный шаблон) | Контент-календарь |
| **Later / Planoly** | Планирование публикаций |
| **Canva** | Дизайн карусей и обложек |

---

## Ошибки при планировании

- Публикация без стратегии ("что в голову пришло")
- Все посты одного формата (только Reels или только фото)
- Игнорирование аналитики
- Копирование тренда без адаптации под нишу
- Планирование на месяц вперед (лучше на 1-2 недели)
