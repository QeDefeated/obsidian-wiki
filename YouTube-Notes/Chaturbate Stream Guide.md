## Часть 1: Платформа — как устроен Chaturbate

### 1.1 Базовая модель

| Элемент | Описание |
|---|---|
| Валюта | Токены (1 токен = ~$0.05 для модели) |
| Доход модели | 50–55% от стоимости токенов |
| Минимальный вывод | $50 |
| Выплаты | Чек, ACH, Paxum, ePayService |
| Верификация | Паспорт/ID + селфи с документом + заполненная форма W-8BEN (для не-US) |

### 1.2 Типы аккаунтов и возможности

```
Зритель (серый)     → смотрит бесплатно, не может отправлять токены
Зритель (голубой)   → купил токены, может типать и писать в чат
Фан-клуб            → ежемесячная подписка на модель (настраиваемая цена)
```

### 1.3 Алгоритм и видимость

Chaturbate ранжирует модели на главной странице по:
- **Количество зрителей** в текущий момент (главный фактор)
- **Активность чата** (сообщения + типы)
- **Время онлайн** — свежие стримы часто получают буст
- **Возвратные зрители** — лояльная аудитория повышает позицию
- **Теги** — правильные теги = правильная аудитория

**Практика:** первый час стрима критичен — активные типы и чат в начале поднимают в рейтинге. Стартуй с вовлечения, а не с ожидания.

**Почему OBS, а не браузерный стрим:**
- Оверлеи (тип-меню, цели, алерты)
- Сцены (переключение между ракурсами)
- Лучшее качество при том же интернете
- Фильтры камеры (цветокоррекция, размытие фона)
- Интеграция с Lovense

Lovense — стандарт индустрии. Игрушка реагирует на токены в реальном времени.

**Настройка:**

2. Подключить игрушку по Bluetooth
3. Привязать к CB через Lovense Extension → Browser Source в OBS
4. Настроить уровни вибрации:

| Токены | Уровень | Длительность |
|---|---|---|

| 15–49 | Средний | 5 сек |
| 50–99 | Сильный | 10 сек |
| 100–299 | Ультра | 15 сек |
| 300+ | Макс | 30 сек |

**Почему это работает:** зритель видит реакцию модели в реальном времени → зеркальные нейроны (Курпатов, факт 9) → дофаминовая петля (факт 3).

## Часть 9: Кросс-платформенная воронка (CB → OF/Fansly)

### 9.1 Зачем нужна воронка

```
Chaturbate:     Трафик (много бесплатных зрителей)
    ↓
OnlyFans:       Монетизация (подписка, PPV, customs)
    ↓
Fansly:         Резервная платформа + мульти-тиры
    ↓
Snapchat/TG:    VIP-доступ (highest LTV)
```

CB даёт **бесплатный трафик** — тысячи зрителей в час. OF даёт **recurring revenue** — стабильный доход без стрима.

### 9.2 Как конвертировать

| Момент | Фраза |
|---|---|
| Начало стрима | «Кто ещё не подписан на мой OF? Ссылка в bio, там я ещё горячее 🔥» |
| После горячего момента | «Хотите полную версию? Это только на OF...» |
| Приватный контент | «Я только что сняла кое-что для OF... кто подписан — уже видел 😏» |
| Конец стрима | «Если хотите видеть меня каждый день — OF, link in bio!» |

**Что НЕ делать:**
- Не спамить ссылками каждые 5 минут → раздражает
- Не обесценивать CB → «на CB я не показываю ничего, всё на OF» → зрители уйдут с CB тоже
- Не конфликтовать с TOS CB → нельзя продавать контент напрямую в чате

### 9.3 Соотношение контента

```
CB (бесплатно):    70% value — зритель должен получать ценность
OF (подписка):     +20% эксклюзив — то, что нельзя увидеть на CB
Snapchat/TG VIP:   +10% ultra-exclusive — самый личный контент
```

## Часть 10: Безопасность и приватность

### 10.1 Защита личных данных

| Угроза | Защита |

| Голос | Если скрываешь личность — изменённый голос (OBS фильтр) |

| Запись стрима зрителями | Неизбежно → принять как данность, не показывать то, чего стыдишься |

### 10.2 Юридическая безопасность

| Аспект | Действие |

### 10.3 Борьба с негативом

| Ситуация | Действие |
|---|---|
| Тролль в чате | Мод банит, ты не реагируешь |

## Часть 11: Ментальное здоровье

### 11.1 Риски

| Риск | Симптомы |
|---|---|
| Выгорание | Нет желания стримить, раздражительность, усталость |
| Зависимость от валидации | Настроение зависит от количества типов |
| Деперсонализация | Ощущение «я — не я, я — персонаж» |
| Перегрузка ДСМ | Трудность «отключиться», навязчивые мысли о зрителях |
| Стыд / stigma | Страх раскрытия, конфликт с ценностями |

### 11.2 Защита

- **Расписание с выходными** — минимум 1–2 дня/неделю без стримов и соцсетей
- **Чёткое разделение роли и себя** — после стрима осознанно «выходить» из персонажа
- **Физическая активность** — после стрима: прогулка, тренировка, душ → переключить ДСМ
- **Группа поддержки** — другие модели (форумы, Telegram-чаты), терапевт
- **Финансовая подушка** — не стримь, когда плохо себя чувствуешь, из страха «не заработаю»
- **Дневник** — записывать эмоциональное состояние после стримов. Если 3+ дня подряд плохо → пауза
