# Пробиотики при РАС, СДВГ и запорах

> Анализ 49 препаратов из аптеки + рейтинг «что реально работает» для оси кишечник-мозг

---

## Почему это важно

```
┌─────────────────────────────────────────────────────────────┐
│                    ОСЬ КИШЕЧНИК — МОЗГ                      │
│                                                              │
│   Кишечник (90% серотонина)                                  │
│       ↓ блуждающий нерв (vagus)                              │
│   Мозг (настроение, внимание, поведение)                     │
│                                                              │
│   При РАС/СДВГ: дисбиоз → воспаление → усиление симптомов   │
│   Запоры: ↑ у 30-70% детей с РАС                             │
│                                                              │
│   Пробиотики → восстановление микробиома                     │
│            → ↓ воспаление, ↑ нейромедиаторы                  │
│            → улучшение ЖКТ + поведения                       │
└─────────────────────────────────────────────────────────────┘
```

**Ключевые факты:**
- У детей с РАС часто снижены Bifidobacterium и Prevotella
- Запоры — самая частая ЖКТ-жалоба при РАС (30-70%)
- L. rhamnosus GG в одном РКИ снизил риск СДВГ при раннем приёме
- 90% серотонина производится в кишечнике → прямая связь с настроением

## ТОП-рейтинг из списка аптеки

### 🏆 ТОП-5 — лучший выбор при РАС + СДВГ + запоры

#### 1. Максилак Бэби саше x 10 — 3,200 ֏ (дети) / Максилак капс x 10 — 3,450 ֏ (взрослые)

**Почему #1:** Синбиотик (пробиотик + пребиотик ФОС). 9 штаммов:
- ✓ L. rhamnosus — ключевой при СДВГ + РАС
- ✓ B. longum — противовоспалительный
- ✓ B. breve — специфически важен при РАС
- ✓ L. casei — помогает при запорах
- ✓ L. acidophilus, L. plantarum, L. helveticus, B. bifidum, S. thermophilus

**Пребиотик в составе** — кормит полезные бактерии, усиливает эффект

| Параметр | Оценка |
|---|---|
| Релевантность при РАС | ★★★★★ |
| Релевантность при СДВГ | ★★★★☆ |

| Цена/качество | ★★★★★ |

**Почему #2:** Премиальное качество Jarrow Formulas (США). 8 штаммов с энтеросолюбильной оболочкой — бактерии гарантированно доходят до кишечника.

- ✓ L. rhamnosus, L. casei, L. plantarum, L. acidophilus
- ✓ B. longum, B. breve, B. lactis, L. helveticus
- ✓ Энтеросолюбильное покрытие = максимальная выживаемость

| Параметр | Оценка |

| Релевантность при СДВГ | ★★★★☆ |

- ✓ Высокая доза = быстрое заселение кишечника
- ✓ Бифидо + Лакто комплекс
- ⚠ Только 10 капсул — короткий курс

| Параметр | Оценка |
|---|---|

| Помощь при запорах | ★★★★☆ |
| Цена/качество | ★★★☆☆ (10 дней) |
| Удобство | ★★★☆☆ |

## Пребиотики: чем кормить бактерии

Пробиотики без пребиотиков — как растения без удобрений. Что добавить в рацион:

| Пребиотик | Источник | Эффект |
|---|---|---|
| **ФОС (фруктоолигосахариды)** | Лук, чеснок, банан, спаржа | Кормит бифидобактерии |
| **ГОС (галактоолигосахариды)** | Молочные продукты, бобовые | ↑ Bifidobacterium и Lactobacillus |
| **Инулин** | Цикорий, топинамбур, артишок | Размягчает стул, ↑ транзит |
| **Резистентный крахмал** | Охлаждённый рис/картофель, зелёный банан | Кормит бутират-продуцирующие бактерии |
| **Пектин** | Яблоки, цитрусовые | Мягкий пребиотик, хорошо переносится |

> **Совет:** Максилак уже содержит пребиотик (ФОС) — ещё одна причина, почему он #1.

## Важные правила приёма

1. **Начинать с малой дозы** — особенно при РАС. Резкое изменение микробиома может временно усилить симптомы (die-off реакция)
2. **Принимать натощак или за 30 мин до еды** — кислотность желудка ниже = больше бактерий выживает
3. **Курс минимум 8-12 недель** — эффект на ось кишечник-мозг накопительный
4. **Хранить в холодильнике** (если не указано иное) — живые бактерии чувствительны к теплу
5. **Не совмещать с антибиотиками** — принимать с разницей минимум 2-3 часа
6. **Вода** — достаточное питьё критически важно при запорах (30 мл/кг веса)
7. **Клетчатка** — постепенно увеличивать в рационе параллельно с пробиотиками

## Быстрое решение

- **Ребёнок с РАС + запоры →** Максилак Бэби + Бревофидропс
- **Ребёнок с СДВГ + запоры →** Максилак Бэби или Линекс форте
- **Взрослый с СДВГ →** Джарро-Дофилус ЕПС или Максилак
- **Только запоры →** Линекс форте (BB-12)
- **Бюджет ограничен →** Бифидомакс 90 капс (4,690 ֏ на 3 мес)
- **Ударный курс →** Бифицин 120 млрд (10 дней) → Максилак (поддержка)

- ❌ **Энтерожермина** — Bacillus clausii, слабо при запорах
