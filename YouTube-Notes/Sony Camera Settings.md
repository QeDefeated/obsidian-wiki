## 7 хаков и настроек

### 1. Picture Profile: S-Cinetone
- Используй **S-Cinetone** как основной профиль
- Камера создана для этого профиля - минимум цветокоррекции
- Не гонись за S-Log3, если не умеешь грейдить
- S-Cinetone = готовая картинка "из коробки"

> **Правило:** Не пытайся освоить мануальный режим до того, как получишь хорошие результаты с S-Cinetone и полу-авто

### 2. Частота кадров и затвор
| Ситуация | FPS | Затвор |
|----------|-----|--------|
| Основная съемка | 24fps или 25fps | 1/50s |
| Обычные видео | 30fps | 1/60s |
| Слоу-мо / B-Roll | 60fps | 1/120s |

**Правило 180 градусов:** Скорость затвора = удвоенный FPS

### 3. Автофокус
- **Eye AF** (автофокус по глазам) - ОБЯЗАТЕЛЬНО включить
- **Tracking** - следящий автофокус для влогов
- Сенсорный экран для переключения фокуса между объектами

### 4. Стабилизация
| Режим | Когда использовать |
|-------|-------------------|
| **Active / Dynamic** | Съемка с рук, влоги |
| **Standard** | На штативе или гимбале |
| **Off** | Профессиональная работа на рельсах |

### 5. Баланс белого
- **Auto** для большинства ситуаций (Sony AWB хороший)
- Ручной при смешанном освещении
- Примерные значения: дневной свет ~5600K, лампы ~3200K

### 6. ISO и экспозиция
- Держи ISO как можно ниже для минимума шума
- ZV-E1: отличная работа до ISO 12800
- ZV-E10: старайся не выше ISO 3200
- Используй ND-фильтр при ярком свете

### 7. Формат записи
- **XAVC S 4K** - оптимальный баланс качества и размера
- 10-bit 4:2:2 для максимального качества
- Быстрая SD-карта обязательна (V60 или V90)

## Частые ошибки

- Съемка в S-Log без понимания экспозиции
- Забытый Eye AF
- Неправильный баланс белого при искусственном свете
- Съемка в 60fps когда не нужен слоу-мо (занимает больше места)
- Перегрев камеры при длительной записи 4K (особенно ZV-E10)

---

## Борьба с перегревом

- Не снимай на солнце дольше 15-20 минут
- Открой экран для вентиляции
- Снимай короткими клипами вместо непрерывной записи
- Используй USB-C питание на ZV-E1 при стационарной съемке
